# Donatier Template

Template web editable para Donatier Studio.

## Cambiar colores
Edita `assets/css/root.css`:

```css
--primary-color: #7c3aed;
--secondary-color: #22d3ee;
```

## Archivos
- `index.html`: página principal.
- `pages/resources.html`: catálogo de recursos.
- `pages/docs.html`: documentación.
- `pages/contact.html`: contacto/custom setups.
- `assets/css/root.css`: colores y variables.
- `assets/js/main.js`: menú mobile, año automático y animaciones.
